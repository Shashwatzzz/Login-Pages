# Login-Pages
This project is combination of clone user login pages of spotify,facebook and netflix.<br>

The project contains three major repositories Facebook, Spotify and Netflix.<br>
Each representing respective login page.<br>

<h1>Running and testing the project files.</h1><br>

<h4>For running and testing the project we can either use the traditional port forwarding method or we can use a prebuilt live server. </h4>
<h2>Downloading the project in local host.</h2><br>
<h3>To get the git project in local host.</h3><br>
<h4>Use command git clone < link of the project > in the command prompt or code editor terminal</h4>
<h2>Launching the project in local host.</h2>
After the installation of project in local host we can either use prot forwarding or live server. I have used the live server to launch the project.
